# 真机验收清单（PWA · 约 5 分钟）

以下项目自动化模拟不了，需要在一部真实手机上过一遍。前置：站点已通过
HTTPS 公网地址访问（GitHub Pages / Cloudflare Pages 均可，localhost 不算）。

## 1. 安装到主屏（约 1 分钟）

- [ ] Chrome/Edge（Android）：地址栏右侧「安装应用」或菜单「添加到主屏幕」可点击，
      安装后主屏出现 **CookMyFridge 图标（橙底煎蛋 PNG，不是默认地球）**。
- [ ] iOS Safari：分享 →「添加到主屏幕」，主屏出现同样的图标（apple-touch-icon）。
- [ ] 安装后点击图标启动，**没有浏览器地址栏**（独立窗口 standalone）。

## 2. 启动画面与图标（约 30 秒）

- [ ] 冷启动 App 时先出现橙色启动画面（非白屏闪烁），随后进入首页。
- [ ] 系统应用列表/最近任务里名称显示为「冰箱开饭」，图标清晰无拉伸裁切
      （maskable 图标应完整显示在圆角/圆形蒙版内）。

## 3. 离线打开（约 1 分钟）

- [ ] 首次联网打开过站点一次（让 Service Worker 装完资源）。
- [ ] 开飞行模式 → 从主屏启动 App → 首页食材墙正常显示（不是断网恐龙/白屏）。
- [ ] 离线状态点两三种食材 → 结果页正常出菜谱卡片。
- [ ] 直接打开某个菜谱深链（如从系统分享历史里点 recipe.html?id=r001）→
      打开的是该菜谱而不是首页。
- [ ] 菜单页打开 → 之前生成的菜单还在（localStorage 持久）。

## 4. 更新与返回手势（约 1 分钟）

- [ ] 有新版本部署后，杀掉 App 重开两次：第二次应看到新内容
      （SW 换缓存后第一个网络优先的页面壳拿到新 HTML）。
- [ ] Android 返回手势：菜谱详情 → 返回 → 回到结果页而非直接退出
      （多页导航历史正常入栈）。
- [ ] iOS 左滑返回同样生效。

## 5. 快速抽查（约 1 分钟）

- [ ] 日历订阅：菜单页「开启订阅」→ 复制 webcal 链接加入系统日历 →
      日历里能看到未来午餐/晚餐事件。
- [ ] 二维码分享：菜谱详情「生成分享图」→ 分享图上有二维码，用另一台手机
      扫码能打开同一菜谱。
- [ ] 横竖屏切换首页，食材墙布局不横向溢出。

## 发现问题的回报格式

哪一项 + 现象 + 机型/系统版本 + 浏览器版本，例如：
「2. 启动画面白屏 2 秒才出首页 / 小米 13 / MIUI 15 / Chrome 120」。
