# 交接文档（断点续作手册）

> 目的：任何时候中断，新会话读完本文件 + `实施进度.md` 即可无缝接手。

## 1. 项目是什么

CookMyFridge（冰箱开饭）：用户点选冰箱食材 → 数据集检索（Cook Now / Almost There）+ AI 创意（AI Wildcard），产物为可直接托管的静态站点。完整背景见 `项目产品定位.md`。

## 2. 环境与关键路径

- Python 3.13（运行时仅用标准库；测试用 pytest）。
- git：`C:\Program Files\Git\cmd\git.exe`（不在 PATH，命令需用绝对路径）。
- GLM 密钥外部 .env：`D:\Py\PyCharmProjects\Langchain\lc-course\.env`
  - 代码通过 `config.zhipu_settings()` 读取，密钥不入库。
  - 可用环境变量 `COOKMYFRIDGE_ENV_FILE` 覆盖 .env 路径。
- 模型：`glm-4-flash`（OpenAI 兼容 `/chat/completions`）。

## 3. 目录地图

| 路径 | 用途 |
|---|---|
| `src/cookmyfridge/` | 领域模型、目录、归一化、校验、LLM、检索、构建 |
| `tests/` | pytest 全量测试（conftest 自动注入 src 路径） |
| `data/curated/` | 人工/AI 菜谱 JSONL |
| `data/catalog/` | 构建导出的食材目录 JSON |
| `data/raw/` | 外部原始数据（如有） |
| `web/` | 静态站点源码（HTML/CSS/JS） |
| `site/` | 构建产物（可直接托管） |
| `docs/` | 产品、进度、踩坑、交接、架构等文档 |

## 4. 常用命令

```powershell
# 测试
cd "D:\Visual Studio Code\Something\CookMyFridge"
python -m pytest tests -q

# git（用绝对路径）
& "C:\Program Files\Git\cmd\git.exe" -C "D:\Visual Studio Code\Something\CookMyFridge" status
```

## 6. 工作纪律（用户明确要求）

1. 小步提交，每个可工作的增量即 commit。
2. 深度测试，交付前跑全量 pytest。
3. 每次踩坑写入 `踩坑记录.md`，进度写入 `实施进度.md`，断点更新本文件。
4. AI 内容必须结构化校验 + 明确 AI 标识 + 安全提示。
5. 用户未插话即默许继续开发与合理拓展。
